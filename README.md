# Trac
本项目现有功能是时间记录与统计。

该项目除 `README.md` 外完全由Codex编写，采用的模型包括GPT-5.5 medium和GPT-5.6 sol medium，以下的“核心功能”和“UI设计”部分为提供给Codex的初始提示词。

## 核心功能
### 事件
- 事件分为日常、习惯、待办三类，用户可以自行添加事件
- 每个事件包含以下信息：
    - 事件类型（如日常、习惯、待办）
    - 事件名称
    - 事件标签（用户可自行增减标签，例如英语、微积分等，仅针对待办和习惯事件）
    - 事件分类（用户可自行增减分类，例如学习、作业、预习等，所有事件初始设置为默认分类）
    - 事件重要和紧急程度（重要紧急、重要不紧急、不重要紧急、不重要不紧急，仅针对待办事项，紧急程度依据DDL的远近来评判）
    - 事件工作量（分为1-5共5个等级，仅针对待办事项）
    - 事件指标（用户可选择事件是否有指标，指标是一个数字加上一段用户自定义的提示，例如“背了50个单词”，仅针对习惯事件）
- 完成含有指标的习惯事件时，提示用户输入指标数值，并将该数值记录到事件数据中

### 时间记录
- 用户从早上起床起到晚上睡觉前，可以随时随地切换当前正在做的“事件”
- 每次可以选择事件列表中的事件切换，事件列表按照日常、重要紧急的待办、不重要紧急的待办、重要不紧急的待办、不重要不紧急的待办、习惯分区展示供用户选择
- 每次切换事件后，记录当前时间为当前事件的结束时间和下一事件的开始时间，并把用于做当前事件的时长记录到该事件数据中，如果当前事件是待办事件，询问用户是否已完成。

### 统计分析
- 用户可以查看每天、每周、每月的事件统计数据，包括：
    - 在每件日常事件上耗费的时间、在所有日常事件上耗费的时间总和
    - 用于进行习惯和待办事件的时间总和、用于进行每个标签的时间总和、用于进行每个分类的时间总和
    - 完成的待办事件的总工作量
    - 习惯事件的指标变化
- 统计数据可以以折线图或热力图的方式展示

## UI设计
- 采用Material Icons图标库，使用Material Design风格设计界面
- 以时间记录为主界面，展示一条时间轴列出用户此前每段时间所做的事件，并着重表示当前时刻；同时列出当前正在进行的事件和已经经过的时间

## 一些支撑这个项目的分析与思考
本项目存在的唯一理由是**解决我的短视频上瘾问题**，核心需求背后最核心的问题是**探究我为什么会对短视频上瘾**。

我发现我仅仅会对小红书上瘾，对B站、抖音、知乎、众多游戏都没有成瘾性。

+ 抖音：我深知其缺乏营养与容易成瘾，因此坚决不碰不下载
+ B站：首先B站是有用的软件，没办法一删了之。我深知视频耗时不愿意轻易碰，且B站已经被我养成了一定的内容偏好，部分推荐较硬核容易注意力涣散
+ 知乎：推荐算法有点烂，老是刷到相同问题的帖子，没啥新意，注意力无法保持
+ 游戏：坚决不碰成瘾性游戏。平时玩的游戏需要一定沉浸的注意力成本。
+ 小红书：首先小红书是有用的软件，没办法一删了之。通常只想刷一会图文内容，想着不会浪费太多时间。然后控制不住点开短视频。然后控制不住刷。

通过以上分析我得出的结论是**注意力是成瘾问题的核心**。

> **命题1** 真正提升能力的任务需要高度集中的注意力。
>
> **命题2** 高度集中的注意力往往无法长时间保持；单调的内容下注意力往往无法长时间保持；不需要过度集中注意力且持续有变化的新内容输入的情况下注意力最容易保持。
>
> **命题3** 注意力的转移有一定阈值，并且阈值根据前序和后序时间相异。通常仅系统1/潜意识参与的习惯性事件序列之间的注意力转移阈值会较低；需要经过的步骤越少注意力转移的阈值越低。  
>
> **命题4** 注意力转移的阈值往往依据心理感知的“被观测程度”与“束缚感”而改变。例如在图书馆/有人的教室进入学习状态的阈值会降低，刷视频的阈值会升高；而在宿舍/只有我一个人的教室/家里则反之。
>

仅针对我个人而言，注意力从日常任务（通勤、吃饭、上课、洗漱）转移到高集中任务的阈值最高，转移入游戏的阈值次之，转移入某个未打开的短视频APP的阈值再次之，但从日常任务转移到图文内容、注意力在同一个APP下的转移的阈值是及其低的。

根据以上结论，我的相应方法论是**我可以在注意力转换的中间时刻添加一个事件，可以起到催化剂的效果**。这件事X需要满足以下性质：

> **性质1** 从其他任意事件转移到事件X的注意力阈值需要极低。
>
> **性质2** 从事件X转移到高度集中注意力任务上的注意力阈值需要比原本更低，转移到娱乐事件上的注意力阈值需要比原本高得多。
>

首先，我认为**堵不如疏**。之前一直采用手机默认的“健康使用手机”功能为小红书设定使用时间上限，但随着延迟15分钟这个动作的心理阈值降低，这个中间事件的催化作用几乎为0。因此我提出的方针是**避免接触不如客观记录**，我可以在打开小红书之前加一步时间记录，在关闭小红书之后加一步时间记录，在一天之后看看我的注意力在每一件事上停留了多久。

针对性质1，依据命题3，这个事件的载体只能是我的手机。这个事件最好能嵌入我的已有应用习惯，可以进一步降低阈值。不过鉴于最近开发时间不多，而且也没有想好如何嵌入，暂定编写网页，将网页添加到手机主页上最显眼最容易接触的位置。

针对性质2，依据命题4，这个阈值的变化只能来自于心理因素。我需要让记录下来的时间以各种统计方式被之后的我反复阅读，必须要让刷视频和做任务的时间形成鲜明对比，这样我在转移注意力的时候会有一种被未来的自己观测的束缚感。
